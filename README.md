This is Bombable MPCarriers Compilation for Flightgear Flight Simulator and Bombable-6.0 Addon. 
_______________________________________________________________________________________________

Installation: Make backup of fgdata/models/Geometry/All Carriers. Copy Aircraft, AI and Models folders into your
 fgdata directory and overwrite all files. 

Bombable MPCarriers are compatible with default MPCarriers, however, some feautures as MP lights and elevators will fully work only at Nimitz at the time.

To change position of MPCarrier, navigate to fgdata/AI folder and find desired Carrier. Open the file and
 change latitude and longitude coordinates.
